# Portfolio Site Workflow

一个用于创建和迭代个人作品集网站的 Codex Skill。它适合求职作品集、个人主页和项目展示页：从简历/作品材料中整理事实，建立视觉风格和交互，并在获得授权后完成公开部署。

![Portfolio Site Workflow 预览图](./portfolio-workflow-preview.png)

> 从洞察、设计到验证：将个人经历沉淀为有辨识度、可分享的作品集网站。

## 它能做什么

- 从简历、项目资料和链接中提取可公开的个人经历与项目事实。
- 将视觉参考转译成独特的配色、排版、材质和交互，而不是复制原网站。
- 为项目卡片与详情页组织「背景 → 洞察 → 策略 → 实验 → 迭代」的叙事。
- 处理头像、生活照或风格化插画，并优化为网页可用资源。
- 检查页面的移动端、键盘操作、动效降级、外链与公开访问状态。
- 在明确授权后部署站点或整理可上传到代码托管平台的源码。

## 安装

1. 下载本仓库中的 `portfolio-site-workflow-skill.zip`。
2. 解压后，得到 `portfolio-site-workflow` 文件夹。
3. 将该文件夹复制到 Codex 的 Skills 目录：

   - Windows：`C:\Users\你的用户名\.codex\skills\`
   - macOS / Linux：`~/.codex/skills/`

4. 新开一个 Codex 对话；它会自动发现这个 Skill。

## 使用方式

在新对话中直接说明需求，或显式调用：

```text
使用 $portfolio-site-workflow，基于我的简历和作品资料搭建一个产品经理求职作品集。
风格参考：……
我希望展示的项目：……
公开联系方式：……
```

建议同时提供：

- 简历 PDF 或工作经历文本；
- 一句话定位、目标岗位和希望展示的姓名/网名；
- 项目背景、你的职责、成果证据、截图或在线链接；
- 喜欢的网站截图或链接；
- 希望公开的邮箱、微信、电话或社交主页；
- 头像/生活照（仅在希望出现在网页中时提供）。

## 发布前检查

发布作品集前，请确认：

- 项目数据、截图和公司信息均可公开；
- 联系方式确实希望展示在公开网页；
- 外部演示链接可访问；
- 部署链接没有登录、密码或组织 SSO 限制。

## 隐私说明

Skill 会把公开内容与私人材料分开处理。部署、创建仓库、公开联系方式或上传个人图片，都应由网站主人明确授权后再执行。
